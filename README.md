# 📄 Resume Builder (HTML & CSS Only)

A simple and elegant **Resume Builder website** created using **only HTML and CSS**.
This project is perfect for beginners who want to design a resume layout without using JavaScript or any backend.

The user can easily edit the HTML file and replace the content with their own information.

---

## ✅ Features

✔️ Built using **ONLY HTML & CSS**
✔️ Clean & professional resume layout
✔️ Easy to customize
✔️ Sections for:

* Name & Profile
* About Me
* Skills
* Education
* Experience
* Projects
* Contact Information

✔️ Fully responsive
✔️ Print-ready resume design
✔️ Beginner-friendly code

---

## 💻 Technologies Used

* Google Fonts

## 🛠️ How To Use

1. Download / Clone the repository

```
git clone https://github.com/your-username/resume-builder.git
```

2. Open `index.html` in your browser.

3. To edit your resume:

* Open `index.html` in VS Code
* Replace the demo content with your own information
* Save and refresh the browser

4. To print:
   Press `Ctrl + P` and save as PDF.
